Every file follows the same depth pattern:
- **What it is** (plain-language definition)
- **Why it matters** (real production reason, not textbook)
- **How it works** (mechanics/diagram)
- **Legacy vs modern** (what changed and why)
- **Cloud mapping** (AWS / Azure / GCP equivalents where relevant)
- **Interview traps** (common gotchas)
