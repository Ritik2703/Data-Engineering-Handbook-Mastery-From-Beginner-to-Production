# 📚 The Ultimate Data Engineering Resource List

Curated YouTube channels, blogs, books, and courses — beyond what's already listed in `01-fundamentals/resources/resources.md`. Use this alongside the repo, not instead of it.

## 🎥 YouTube Channels — India-Focused / Practical Project-Based

| Channel | Best For |
|---|---|
| **Sumit Mittal (TrendyTech)** | The most well-known channel for interview-style data engineering content in India — Spark, Kafka, Hadoop/Hive alongside modern tooling, strong system-design-style interview question breakdowns (fault-tolerant ingestion, late-arriving events, partitioning) |
| **Ansh Lamba** | End-to-end project walkthroughs specifically on Azure (ADF, Databricks, Synapse, Microsoft Fabric), and increasingly AI/LLM topics for the "data domain" (RAG, vector DBs, AI agents) — great for Azure-track learners |
| **Shashank Mishra (Data Engineering Simplified)** | Spark/Kafka on cloud platforms, interview-style mock rounds |
| **Ankit Bansal** | SQL and data engineering interview preparation |
| **Darshil Parmar** | Data engineering projects and roadmap-style content |
| **Ankur Ranjan (Big Data Show)** | Big data and interview-oriented content |

## 📖 Books (recap + expand on `01-fundamentals/resources/resources.md`)

| Book | Why It Matters |
|---|---|
| **Fundamentals of Data Engineering** — Reis & Housley | The closest thing to a definitive modern DE textbook, mirrors this repo's "concepts before tools" philosophy |
| **Designing Data-Intensive Applications** — Martin Kleppmann | The system-design bible; directly underlies much of module 11's reasoning about consistency, replication, and reliability |
| **The Data Warehouse Toolkit** — Ralph Kimball | THE dimensional modeling reference; foundational to module 01/05's data modeling content |
| **Streaming Systems** — Tyler Akidau | The deepest treatment of batch vs streaming, watermarks, and windowing available |
| **The Phoenix Project** / **The Unicorn Project** — Gene Kim | Novel-format books that make DevOps culture (module 10) genuinely click for many readers |
| **Site Reliability Engineering** (free online, Google) | The original SRE book — directly informs module 10's monitoring/observability content |

## How to Use This List Without Getting Overwhelmed
```
Don't try to consume everything here. Pick ONE YouTube channel matching
your current learning stage (recap `12-interview-prep/09`'s 90-day plan),
ONE book to read alongside this repo (Fundamentals of Data Engineering
is the single best complement), and follow 2-3 blogs for staying current
— depth on a few sources beats shallow exposure to everything.
```
